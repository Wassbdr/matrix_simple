# Internal documentation

This directory contains artifacts produced for the original internship
review (EPITA, 2026): weekly progress notes, the full internship report,
and the hand-off documents shared with the academic supervisor and the
host company.

These files are kept in the repository for **traceability and
reproducibility of the published results**, not as user-facing
documentation. They are written in French and reference internal
deadlines, supervisors, and hand-off conventions that are not relevant
to external users of the codebase.

If you are looking for user-facing documentation, start with:

- The top-level [`README.md`](../../README.md) — installation, quick start, results
- [`docs/PAPER_BENCHMARKS.md`](../PAPER_BENCHMARKS.md) — detailed benchmark commentary
- [`docs/ANALYSIS_SIM_VS_REAL.md`](../ANALYSIS_SIM_VS_REAL.md) — simulated-vs-real gap analysis
- [`docs/ANALYSIS_MULTIMODAL.md`](../ANALYSIS_MULTIMODAL.md) — multimodal extension analysis
- [`docs/COMPARABILITY_MATRIX.md`](../COMPARABILITY_MATRIX.md) — comparability vs. published baselines
